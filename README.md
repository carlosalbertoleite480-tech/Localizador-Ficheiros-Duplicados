Este pacote inclui um workflow GitHub Actions para compilar a aplicação num ambiente Windows alojado, sem exigir Python no computador onde o programa será utilizado.

Leia `COMO_GERAR_EXE_AUTOMATICAMENTE.txt` para os passos completos. O executável ainda não está incluído neste ZIP: será produzido pelo workflow depois de este ser carregado para um repositório GitHub e executado.
