Esta é uma versão de preparação do código-fonte. Ainda não inclui um executável Windows pré-compilado.

FUNCIONALIDADES
- Análise de pastas e discos à procura de duplicados exatos através de SHA-256.
- Deteção aproximada de imagens visualmente semelhantes.
- Separadores Lista e Imagens.
- Lista compacta com tipo, tamanho e nome do ficheiro.
- Ao selecionar uma linha, a localização completa aparece por baixo da lista.
- Grelha de imagens com miniaturas e botão «Ver localização».
- Exportação dos resultados para CSV.
- Envio para a Reciclagem apenas após seleção e confirmação explícita.
- Não elimina ficheiros automaticamente.

COMO GERAR A VERSÃO AUTÓNOMA
1. Num computador Windows com Python já instalado, extraia todo este ZIP para uma pasta normal.
2. Execute COMPILAR_NO_WINDOWS.bat e aguarde pela conclusão.
3. Confirme que existe dist\Localizador_Ficheiros_Duplicados\Localizador_Ficheiros_Duplicados.exe.
4. Copie a pasta COMPLETA dist\Localizador_Ficheiros_Duplicados para o local onde pretende usar o programa.
5. Teste o EXE antes de desinstalar Python do computador de compilação.

IMPORTANTE SOBRE PYTHON
Python é necessário apenas no computador e durante a compilação. O pacote gerado pelo PyInstaller inclui o interpretador e as dependências, pelo que o computador de destino não precisa de ter Python instalado. Este ZIP, por si só, ainda não é o executável autónomo.

TESTE RECOMENDADO
Antes de utilizar com ficheiros pessoais, teste numa pasta de ensaio que contenha duas cópias de um ficheiro e algumas imagens duplicadas. Confirme a lista, a pré-visualização, a exportação CSV e a caixa de confirmação da Reciclagem.

NOTA
A comparação perceptual de imagens é aproximada. Reveja sempre os resultados antes de enviar qualquer ficheiro para a Reciclagem.
